Katakana is a one to one match of Hiragana, but is used for loan words and is a phonetic lettering system.

|     | a    | i        | u         | e    | o    | -   |
| --- | ---- | -------- | --------- | ---- | ---- | --- |
| -   | ア   | イ        | ウ        | エ   | オ   |     |
| k   | カ   | キ        | ク        | ケ   | コ   |     |
| s   | サ   | シ<br>shi | ス        | セ   | ソ   |     |
| t   | タ   | チ<br>chi | ツ<br>tsu | テ   | ト   |     |
| n   | ナ   | ニ        | ヌ        | ネ   | ノ   | ン  |
| h   | ハ   | ヒ        | フ<br>fu  | ヘ   | ホ   |     |
| m   | マ   | ミ        | ム        | メ   | モ   |     |
| r   | ラ   | リ        | ル        | レ   | ロ   |     |
| y   | ヤ   |           | ユ        |      | ヨ   |     |
| w   | ワ   |           |           |      | ヲ   |     |

Any word that is of foreign origin is "converted" into a closely matching word crafted from Katakana characters.
e.g. America = アメリカ

Just like Hiragana, some of the consonant rows can be applied a *dakuten* mark denoted by ( ゛) to become voiced consonants. This changes the sound of the consonant:
- k --> g
- s --> z 
- t --> d
- h --> b

|     | a    | i        | u         | e   | o    |
| --- | ---- | -------- | --------- | --- | ---- |
| g   | ガ   | ギ       | グ        | ゲ   | ゴ   |
| z   | ザ   | ジ<br>ji | ズ        | ゼ   | ゾ   |
| d   | ダ   | ヂ<br>ji | ヅ<br>dzu | デ   | ド   |
| b   | バ   | ビ       | ブ        | ベ   | ボ   |

The H-row of the Katakana table can also be given a *handakuten* mark denoted by ( ゜). This changes the sound of the consonant:
- h --> p

|     | a   | i   | u   | e   | o   |
| --- | --- | --- | --- | --- | --- |
| p   | パ   | ピ   | プ   | ペ   | ポ   |

The Y-row characters have what is called the "small" version which can be added to Katakana characters ending in -i, each replacing the -i postfix with itself

|     | small ya | small yu | small yo |
| --- | -------- | -------- | -------- |
| ki  | キャ     | キュ      | キョ     |
| shi | シャ     | シュ      | ショ     |
| chi | チャ     | ヂュ      | ヂョ     |
| ni  | ニャ     | ニュ      | ニョ     |
| hi  | ヒャ     | ヒュ      | ヒョ     |
| mi  | ミャ     | ミュ      | ミョ     |
| ri  | リャ     | リュ      | リョ     |
| gi  | ギャ     | ギュ      | ギョ     |
| ji  | ジャ     | ジュ      | ジョ     |
| dzi | ヂャ     | ヂュ      | ヂョ     |
| bi  | ビャ     | ビュ      | ビョ     |

The tsu (ツ) character also has a "small" version called *sokuon* which is used to elongate the consonant part of the consonant-vowel that _follows it_ and can be applied to most Katakana characters with the exception of:
- the vowels row (simply add a second vowel )
- the N-row, as the singular n (ン) is added instead
- voiced consonants
